# UAudit: маршрутизация операционных проверок на iMac

**Статус:** предложено к реализации после согласования

**Дата:** 2026-08-18

**Ветка:** `docs/uaudit-imac-operations`

**Базовый commit:** `77ad18c9f6c8ba1146494d33d30bea93aebc6647` (`origin/develop`)

## Цель и критерий успеха

Закрепить для Codex и операторов единственное правило: локальный checkout
UAudit в Gimle-Palace служит для разработки и изменения конфигурации, а
операционные запросы о текущем состоянии, логах, запусках и данных UAudit
выполняются на iMac через настроенный SSH-host `imac-ssh.ant013.work` и его
Paperclip runtime.

Успех означает, что следующий запрос вида «покажи логи/статус UAudit за
период» не начинает поиск в локальном checkout и не выдаёт его содержимое как
runtime-данные. Ответ содержит источник на iMac, проверенный период и явное
состояние каждого доступного операционного артефакта.

## Предпосылки и принятые решения

- Локальный проект `Gimle-Palace` является клоном репозитория, который
  обслуживает Paperclip-сервис на iMac; это не источник живых данных UAudit.
- Канонический SSH alias: `imac-ssh.ant013.work`. Перед поиском исполнитель
  проверяет, что подключился к iMac, а не к локальному MacBook.
- «Последние два дня» по умолчанию означает скользящие 48 часов, если
  пользователь не задал календарный интервал или часовой пояс.
- Недостаток аутентификации сначала сообщается как блокер. Разрешённые
  fallback-источники учётных данных: `/Users/ant013/Android/Gimle-Palace-native`
  и `/Users/ant013/Android/Gimle-Palace-native-dev`. Их нельзя копировать,
  печатать или переносить заранее; обращение к ним допускается только после
  фактической неудачи SSH-аутентификации и только в объёме, необходимом для
  подключения.
- Никакие секреты, токены, приватные ключи и значения env-файлов не попадают в
  runbook, командный вывод или итоговый отчёт.

## Scope

Входит:

- дополнение `AGENTS.md` коротким обязательным маршрутом для операционных
  UAudit-запросов;
- новый подробный runbook в `docs/paperclip-operations/` с безопасной
  последовательностью: SSH preflight, обнаружение реального Paperclip runtime,
  поиск run/log/state-артефактов за период, классификация их состояния и
  отчёт;
- явное разделение development-checkout и runtime на iMac;
- безопасный порядок обработки отсутствующей аутентификации и секретов;
- проверка инструкций на непротиворечивость с `paperclips/runbook-access.md` и
  существующими UAudit delivery/run-state контрактами.

Не входит:

- изменения UAudit runtime, ролей, agent bundles, delivery contract или
  развёртывания на iMac;
- изменение, перенос или ротация учётных данных;
- автоматическое подключение, копирование файлов или сбор логов без прямого
  пользовательского запроса;
- подмена реальных iMac-данных локальными артефактами.

## Затрагиваемые области

- `AGENTS.md` — краткое, исполнимое правило маршрутизации.
- `docs/paperclip-operations/uaudit-imac-operations.md` — новый подробный
  операторский runbook.
- Только при необходимости: существующий индекс/ссылка в
  `docs/paperclip-operations/`, без дублирования правил в generated bundles.

## План реализации

1. Подтвердить SSH-доступ к `imac-ssh.ant013.work` без чтения или вывода
   секретов и зафиксировать remote hostname.
2. На iMac read-only командами обнаружить канонический Paperclip project root,
   расположения UAudit run/log/state-данных и безопасные фильтры по времени.
3. Написать runbook с точными командами, которые не раскрывают секреты, и
   добавить в `AGENTS.md` компактную обязательную ссылку на него.
4. Проверить Markdown links, команды и соответствие существующим правилам
   доступа к runbook; показать diff.

## Критерии приёмки

- Инструкция однозначно требует iMac/Paperclip для любого запроса о live
  UAudit logs/status/data.
- Локальный checkout явно помечен как development-only для таких запросов.
- Runbook включает безопасный SSH preflight и проверку целевого хоста.
- Runbook документирует поиск за скользящие 48 часов и порядок отчёта о
  доступных, отсутствующих и ошибочных артефактах.
- Отсутствие SSH-доступа не приводит к самовольному копированию секретов;
  fallback ограничен указанными путями и фактической необходимостью.
- В новой документации отсутствуют секреты и их значения.
- Изменения ограничены инструкциями и runbook, без runtime/deploy-изменений.

## Верификация

- `git diff --check`.
- Проверка всех Markdown-ссылок на существование локальных файлов.
- Read-only SSH preflight на iMac и read-only обнаружение фактических runtime
  путей; в коммит не включаются журналы или данные iMac.
- Ручная проверка сценариев: успешный доступ, отсутствующая аутентификация,
  пустой период, частичный run и заблокированный run.

## Открытые вопросы

- Точные абсолютные пути Paperclip runtime и UAudit state/log/run-директорий
  на iMac будут установлены безопасным read-only discovery на этапе реализации.
- Если на iMac несколько UAudit runtime-инстансов, runbook должен определить
  их canonical selection rule, а не выбирать первый найденный путь.
