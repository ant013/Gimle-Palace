## Class

`MoneroAdapter` — the class that adapts the Monero blockchain to the app's wallet interface.

## File

`/Users/ant013/Ios/bench-vanilla/Unstoppable/Unstoppable/Core/Adapters/MoneroAdapter.swift`

## Public API

The class itself is declared without an access modifier (so it is `internal` to the app module). Only three members carry an explicit `public` modifier; the remaining externally-visible surface is exposed via protocol conformances (`IAdapter`, `IBalanceAdapter`, `ITransactionsAdapter`, `IDepositAdapter`, `MoneroKitDelegate`) and `internal` members. Listing the full non-private surface that other modules / call sites use:

### Explicitly `public`
- `var explorerTitle: String` — returns "Blockchair"
- `func explorerUrl(transactionHash: String) -> String?`
- `func explorerUrl(address _: String) -> String?`
