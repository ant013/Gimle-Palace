## T5 — 1Inch cross-chain swap in unstoppable-wallet-ios

### Headline finding

**The 1Inch integration in this app does not perform cross-chain swaps.** A user-initiated swap that crosses chains (e.g. Ethereum -> BNB Smart Chain) cannot be routed through 1Inch because the provider explicitly rejects mismatched chains. 1Inch Fusion+ / cross-chain APIs are not wired into the app — only the same-chain Aggregation / Quote / Swap REST endpoints are.

Hard evidence — `OneInchMultiSwapProvider.supports(tokenIn:tokenOut:)`:

```
/Users/ant013/Ios/bench-gimle/Unstoppable/Unstoppable/Modules/MultiSwap/Providers/OneInchMultiSwapProvider.swift:34-43
    override func supports(tokenIn: MarketKit.Token, tokenOut: MarketKit.Token) -> Bool {
        guard tokenIn.blockchainType == tokenOut.blockchainType else {
            return false
        }
        switch tokenIn.blockchainType {
        case .ethereum, .binanceSmartChain, .polygon, .avalanche,
             .optimism, .arbitrumOne, .gnosis, .fantom, .base: return true
        default: return false
        }
    }
```

So when the operator's UI offers swap providers for `ETH(Ethereum) -> BUSD(BSC)`, `OneInchMultiSwapProvider` is filtered out by `MultiSwapProviderManager`. In the current codebase, **cross-chain ETH<->BSC is served by `AllBridgeMultiSwapProvider`** (and for chains it supports, `ThorChainMultiSwapProvider` / `MayaMultiSwapProvider`). `AllBridgeMultiSwapProvider` is the only provider whose code branches on `tokenIn.blockchainType != tokenOut.blockchainType` (`AllBridgeMultiSwapProvider.swift:236, 318, 515`).

### "Which one quotes / signs / builds the route"

- **Quotes the price**: `OneInchMultiSwapProvider.quote(...)` -> `OneInchKit.Kit.quote(networkManager:chain:fromToken:toToken:amount:fee:)` (1Inch `/quote` endpoint).
- **Builds the route / swap transaction (`to`, `data`, `value`, `gasLimit`)**: `OneInchMultiSwapProvider.confirmationQuote(...)` -> `OneInchKit.Kit.swap(networkManager:chain:receiveAddress:fromToken:toToken:amount:slippage:referrer:fee:recipient:gasPrice:)` (1Inch `/swap` endpoint). Result wrapped into `EvmSwapFinalQuote` via the `OneInchKit.Swap.transactionData` extension.
- **Signs**: `Signer.signature(rawTransaction:)` invoked inside `EvmKitWrapper.send(...)` (`EvmKitManager.swift:222`). Broadcast is done by `EvmKit.Kit.send(...)` (or `MerkleTransactionAdapter.send(...)` when MEV protection is on).
- **Pre-swap allowance to router**: `MultiSwapAllowanceHelper` against spender `OneInchKit.Kit.routerAddress(chain:)`.
- **Glue/orchestration**: `MultiSwapSendHandler.sendData(...)` -> `provider.confirmationQuote(...)`; `MultiSwapSendHandler.send(...)` -> `EvmKitWrapper.send(...)`; final persistence via `Core.shared.swapHistoryManager.save(swap:)` and wallet auto-enable.

### To actually do ETH -> BNB Smart Chain in this app

Selected provider is **not** `OneInchMultiSwapProvider`. The user-visible flow is:

```
MultiSwapViewModel
  → MultiSwapProviderManager (filters by supports(tokenIn,tokenOut))
  → AllBridgeMultiSwapProvider                                ← the cross-chain driver
      .quote / .confirmationQuote → AllBridge SDK HTTP        ← quoting + route
      crosschain branch at lines 236, 318, 515
  → MultiSwapSendHandler.send(... EvmSwapFinalQuote ...)
  → EvmKitWrapper.send(...)  on the ORIGIN chain (Ethereum)   ← signing
  → AllBridge bridge contract emits on BSC; provider returns
    `depositAddress` / `providerSwapId` for tracking
```

(`ThorChainMultiSwapProvider` / `MayaMultiSwapProvider` handle other cross-chain pairs that AllBridge doesn't cover, but neither uses 1Inch.)
