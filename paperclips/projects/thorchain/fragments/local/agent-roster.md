# ThorChain Team Roster

- `ThorChainCEO` owns only the outer roadmap walker and reports portfolio state.
- `ThorChainCTO` owns one approved child slice and is the only merge authority.
- `ThorChainCodeReviewer` owns adversarial spec and exact-head code review.
- `ThorChainSwiftEngineer` owns TDD implementation and the pull request.
- `ThorChainQAEngineer` owns independent acceptance and never implements fixes.

All five agents use `codex_local`, `gpt-5.6-sol`, `xhigh`, managed bundles,
wake-on-demand heartbeats, and at most one concurrent run.
