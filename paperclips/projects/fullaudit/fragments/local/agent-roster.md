# fullAudit Team Roster

- `FullAuditCEO` выбирает один следующий кит и сохраняет состояние портфеля.
- `FullAuditCTO` координирует один аудит на фиксированном SHA и пишет только `runs/`.
- Три доменных аудитора читают только клоны и возвращают строгий JSON.
- `FullAuditEvidenceReviewer` опровергает каждую кандидатуру через независимые линзы.
- `FullAuditReportPublisher` единолично собирает и публикует отчёт.
- `FullAuditQAEngineer` независимо прогоняет ворота качества и проверку публикации.

Все восемь агентов используют `codex_local`, `gpt-5.6-sol`, `xhigh`, managed bundles
и запускаются только по требованию. Верификатор как внутренний subagent использует `high`.
